## 🌿 About the lesson

Ecological communities contain many species measured across many sites, so their structure cannot usually be understood one variable at a time. This lesson introduces dissimilarity, transformation, and ordination methods for exploring and interpreting multivariate community data.

## 🎯 Learning goals

By the end of the lesson, participants should be able to:

- recognize the structure of a community-data matrix;
- choose and interpret common dissimilarity measures;
- understand the purpose and assumptions of PCA, CA, NMDS, RDA, and CCA;
- prepare community data for ordination and create interpretable ordination graphics.
